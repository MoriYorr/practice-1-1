## compilerOptions
Здесь размещаются настройки, связанные с компилятором
### target
> версия стандарта языка в которую будет скомпилирован код

### module
> модульная система, которую будет использовать собранное приложение

### moduleResolution
> стратегия которая будет использоваться для импорта модулей, node/classic

### strict
> Дает возможность включить все строгие проверки сразу

### strictNullChecks
> Значения null и undefined можно присваивать только значениям данного типа или типу any
